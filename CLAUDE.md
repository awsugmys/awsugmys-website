## Ground rules

- Static Astro 7 site (pinned 7.4.1, Node 22.22+). `npm run check` and `npm run build` must stay at
  0 errors and 0 warnings.
- Don't modify `infrastructure/`, `.github/workflows/` or `logos/` unless asked. Never run
  `terraform apply`/`destroy` or push to `main` (pushing to `main` deploys) without explicit approval.
- Look: clean, AWS-style technical community site with the Mysore Palace as the motif. No festival
  decoration (fireworks, garlands, bunting). Amazon fonts only; no emoji or non-Latin scripts in
  the UI (use `src/components/ui/Icon.astro`).
- Colours and spacing come from `src/styles/tokens.css` (`light-dark(light, dark)`); check both
  themes at 390px and 1440px (`npm run screenshots`).
- Content lives in `src/content/` (schemas in `src/content.config.ts`). Never invent facts, names,
  dates or stats; take them from a real source and say where they came from.
- Restart the dev server after adding a content collection (otherwise it renders empty).
- Internal links end with a slash. Legacy URLs: posts at `/blog/<filename>/`, tags at `/tags/<slug>/`.

## Hero scene

- Artwork is generated by `npm run assets:hero` from `reference/` (not in git); outputs in
  `src/assets/hero/` are committed (palace images carry a content hash in their names).
- After regenerating: `npm run check:hero-alignment` should report ~0px. After changing the
  elephant's size or `--el-cross`: `npm run check:hero-gait` (planted feet must not drift).
- Animations are transform/opacity only, pause off-screen, and respect `prefers-reduced-motion`.
- Goddess Chamundeshwari rides in the howdah: never use the deity in a joke context (the 404 page
  shows the palace without the elephant).
